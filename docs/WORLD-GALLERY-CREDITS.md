# World gallery preview credits

`world-streets.jpg` is a collection of six actual Sokak 1.6.0 renderer frames. Photographs are cropped, dimmed, defocused and composited with animated-weather frames, then resized and labelled for this overview. Each photographic tile and its adaptation retain the individual terms below. This collection does not replace the original files or their licenses. Layout and labels are by Sokak contributors.

Tiles are listed left to right, first the rain row and then the snow row.
